# Mohammed Alshehri — Professional Portfolio

Business analysis, data analytics, guest experience, Voice of the Customer, and aviation operations.

This static portfolio uses HTML, CSS, and JavaScript. The interactive timekeeping example uses synthetic records. Training and career information distinguish course attendance from current licensing.

## Site files

- `index.html`: portfolio content.
- `styles.css`: responsive design.
- `demo.js`: browser-only timekeeping demonstration.
- `assets/`: images referenced by the portfolio.

No package installation or build step is required. GitHub Pages can serve the site from the root of the main branch. `.nojekyll` keeps the static files unchanged.
